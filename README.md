# Smart Car - FPGA 智能小车系统

基于安路科技 EF2 FPGA 的智能小车控制系统，使用 Verilog HDL 实现，集成循迹、避障、温湿度检测与 LCD 显示功能。

## 项目解决什么问题

传统的智能小车多基于单片机（如 51/STM32）开发，存在以下局限：
- 多传感器实时采集与电机控制需抢占 CPU 资源，响应延迟较高
- PWM 输出、传感器时序模拟等依赖定时器中断，多路并行时调度复杂
- 从传感器输入到电机输出的控制链路存在软件开销

本项目使用纯硬件描述语言（Verilog）在 FPGA 上实现完整的智能小车控制逻辑，所有模块并行运行，具有**微秒级响应**和**确定的时序行为**，适合作为 FPGA 入门与数字系统设计的综合实践项目。

## 主要功能

| 功能模块 | 说明 |
|---------|------|
| **红外循迹** | 4 路 TCRT5000 红外传感器，检测黑线并实现差速转向 |
| **红外避障** | 2 路红外避障传感器，检测到障碍物后自动停车、后退、掉头并搜索赛道 |
| **温湿度采集** | DHT11 单总线温湿度传感器，1Hz 采样频率，带校验和验证 |
| **LCD1602 显示** | 两行 16 字符液晶显示，实时显示温度与湿度 |
| **电机驱动** | L298N 双 H 桥驱动 4 路直流电机，1kHz PWM 调速，占空比 0~100 |
| **蜂鸣器报警** | 避障时蜂鸣器鸣响提示 |

### 循迹控制策略

- 使用 4 路红外传感器（从左到右 `line_sensor[3:0]`）
- 根据黑线偏移位置自动调整左右轮差速：居中直行、轻度偏移一侧反转、严重偏移全速差速转向
- 传感器防抖：三级打拍 + 防抖计数，避免误触发
- 转向刹车：直行转转向时先刹车约 50ms，减少机械冲击
- 冲出赛道记忆：全白时按最后偏移方向继续转弯搜索黑线

### 避障控制策略

状态机流程：
1. **停止**（250ms）— 检测到障碍物立即停车，蜂鸣器响
2. **后退**（250ms）— 倒车留出转弯空间
3. **掉头**（0.8s）— 左正转右反转，原地掉头约 180°
4. **搜索赛道**（最长 4s）— 继续转弯直到检测到黑线，恢复循迹

## 安装方法

### 环境要求

- **操作系统**：Windows 10/11
- **开发工具**：[安路 TD](https://www.anlogic.com/)（Tang Dynasty）6.2 或更高版本
- **下载器**：安路 USB 下载器或兼容 JTAG 下载器

### 安装步骤

1. **安装 TD 软件**
   - 从安路科技官网下载 TD 设计套件
   - 按照安装向导完成安装，安装过程中勾选 USB 驱动

2. **打开项目**
   - 启动 TD 软件
   - 点击 `File` → `Open Project`
   - 选择 `smart_car.al` 打开项目

3. **连接硬件**
   - 将 FPGA 开发板通过 USB 下载器连接到电脑
   - 连接好小车各外设（传感器、电机驱动、LCD 等）
   - 给开发板和电机驱动供电

## 使用方法

### 1. 综合与布局布线

打开项目后，可以直接运行完整流程：

```
点击工具栏 "Run All" 按钮
# 或依次执行：
# 1. Synthesis（综合）
# 2. Physical Design（布局布线）
# 3. Generate Bit File（生成比特流）
```

也可以使用 `smart_car_Runs/` 目录中已有的运行结果。

### 2. 下载程序

1. 点击 `Tools` → `Programmer` 打开下载工具
2. 选择器件型号 `EF2L45BG256B`
3. 添加比特流文件 `smart_car_Runs/best_result/smart_car.bit`
4. 点击 `Program` 下载到 FPGA

### 3. 运行小车

1. 将小车放置在带有黑色循迹线的白色跑道上
2. 按下复位键（低有效复位），小车开始运行
3. LCD1602 第一行显示 "Smart Car V1.0"，第二行显示实时温湿度

### 4. 行为说明

- **正常循迹**：小车沿黑线行驶，根据偏移自动调整方向
- **遇到障碍物**：立即停车 → 蜂鸣器响 → 后退 → 掉头 → 搜索赛道 → 恢复循迹
- **温湿度显示**：每秒更新一次，LCD 第二行格式 `T:XXC H:XX%`

## 输入输出示例

### 引脚分配（部分关键引脚）

| 信号 | 方向 | FPGA 引脚 | 说明 |
|------|------|----------|------|
| clk | 输入 | A8 | 50MHz 系统时钟 |
| rst_n | 输入 | P4 | 异步复位，低有效 |
| dht11 | 双向 | D2 | DHT11 数据线 |
| lcd_rs | 输出 | R1 | LCD 寄存器选择 |
| lcd_rw | 输出 | R3 | LCD 读写控制 |
| lcd_en | 输出 | R4 | LCD 使能 |
| lcd_data[7:0] | 输出 | R7,R6,R5,B6,B5,B4,B3,C2 | LCD 数据总线 |
| line_sensor[3:0] | 输入 | L2,M2,N2,P2 | 循迹传感器（左→右） |
| obs_sensor[1:0] | 输入 | E2,F2 | 避障传感器（左前,右前） |
| IN1A/IN1B | 输出 | A4/A5 | 左前电机方向 |
| IN2A/IN2B | 输出 | D1/C1 | 左后电机方向 |
| IN3A/IN3B | 输出 | B1/A3 | 右前电机方向 |
| IN4A/IN4B | 输出 | F1/E1 | 右后电机方向 |
| PWMA/PWMB | 输出 | G1/H1 | 左侧 PWM |
| PWMC/PWMD | 输出 | J1/K2 | 右侧 PWM |
| buzzer | 输出 | G2 | 蜂鸣器 |

完整引脚约束见 `yinjiao.adc`。

### 循迹传感器输入 → 电机输出 示例

`line_sensor` 位定义：`[3]` 最左，`[0]` 最右；`1` = 检测到黑线，`0` = 白色

| line_sensor | 状态 | 左轮 | 右轮 | 行为 |
|-------------|------|------|------|------|
| `0110` | 居中 | 正转 50% | 正转 50% | 直行 |
| `0010` | 微偏左 | 正转 50% | 正转 50% | 直行 |
| `1000` | 偏左 | 正转 50% | 反转 50% | 右转（差速大） |
| `1100` | 较偏左 | 正转 50% | 反转 50% | 右转 |
| `1110` | 严重偏左 | 正转 50% | 反转 50% | 快速右转 |
| `0001` | 偏右 | 反转 50% | 正转 50% | 左转（差速大） |
| `0011` | 较偏右 | 反转 50% | 正转 50% | 左转 |
| `0111` | 严重偏右 | 反转 50% | 正转 50% | 快速左转 |
| `0000` | 全白（冲出） | 按记忆方向搜索 | 按记忆方向搜索 | 转弯寻线 |

### 避障传感器输入 → 行为示例

`obs_sensor` 位定义：`[1]` 左前，`[0]` 右前；`1` = 无障碍，`0` = 检测到障碍

| obs_sensor | 触发条件 | 行为序列 |
|-----------|---------|---------|
| `10` 或 `01` 或 `00` | 任意一侧检测到障碍 | 停车(250ms) → 后退(250ms) → 左转掉头(0.8s) → 搜索赛道(最长4s) → 恢复循迹 |

### LCD 显示示例

```
┌──────────────────┐
│ Smart Car V1.0   │  ← 第1行：固定显示
│ T:26C H:65%      │  ← 第2行：温度26°C，湿度65%
└──────────────────┘
```

## 参数调优

以下参数可根据实际硬件情况在对应模块中修改：

### sensor_ctrl.v

| 参数 | 默认值 | 说明 |
|------|--------|------|
| DUTY_HIGH | 50 | 直行/大转向占空比 (0-100) |
| DUTY_MID | 50 | 中度转向占空比 |
| DUTY_SLOW | 50 | 小转向占空比 |
| BRAKE_TIME | 2,500,000 | 刹车时间（50MHz 周期数，约 50ms） |
| OBS_TURN_TIME | 40,000,000 | 避障掉头时间（约 0.8s） |
| DEBOUNCE_TOP | 6 | 防抖计数阈值 |

### motor_ctrl.v

| 参数 | 默认值 | 说明 |
|------|--------|------|
| PWM_TOP | 49,999 | PWM 周期（50MHz/50,000 = 1kHz） |

### dht11_ctrl.v

| 参数 | 默认值 | 说明 |
|------|--------|------|
| TIME_20MS | 1,000,000 | DHT11 起始信号低电平时间 |
| TIME_40US | 2,000 | 0/1 判别阈值（>40us 判为 1） |
